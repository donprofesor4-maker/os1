# OS1

Escritorio educativo para primero de primaria: mouse, carpetas y teclado.

Las actividades y los archivos se simulan en el navegador.

## Puntos

Accesible desde la barra de tareas: `actividades/puntos/`. Diez dibujos, clic izquierdo en niveles 1–3, derecho en 4–7 y alternados en 8–10. Sonido apagado por defecto, progreso local y guía visual de mouse en el nivel 4. En el menú solo se muestra el zorro inicial; los demás dibujos conservan la incógnita.
